## Permissions observed

- voiceio: no `/dev/input`, no `input` group, no ydotool. GNOME custom shortcut
  runs `voiceio toggle`, which talks to a Unix socket; typing goes through IBus.
- vocalinux: IBus for typing; its own hotkey wants `/dev/input` (or use the
  D-Bus `--toggle` shortcut, which is toggle-only).
- hex: RemoteDesktop + GlobalShortcuts portals; GNOME prompts once.

## Notes on delivered text

voiceio's *streaming* mode delivered the same utterance with punctuation removed
and one word changed ("escribir" instead of "escribe") because partial passes get
committed early. Raw decode on the same file is punctuated and correct. Setting
`output.streaming = false` makes it decode once on release at the cost of the
live preview.
